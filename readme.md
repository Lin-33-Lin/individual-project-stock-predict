# 校园 FAQ 智能问答小助手

基于大模型检索增强生成（RAG）的轻量化校园问答系统。用户用自然语言提问，系统依据本校权威公开文档作答并附上来源引用；超出知识库范围的问题明确拒答，而不是编造答案。

## 背景与目标

校园信息分散在教务系统、官网、公众号和班级群之间，学生常面临「找不到、看不懂、不敢信」的困境，教师和辅导员则重复答疑负担重。本项目要解决的正是这一真实、高频的问题：

- 对学生：信息获取从「翻找半天」缩短到「数十秒」；
- 对学校：分流常见问题的重复咨询；
- 对课程：完整覆盖「数据收集—整理分析—产品化—评估—可视化」闭环。

系统边界：**只做信息查询，不做业务办理；只面向校园公开信息，不涉及个人数据。**

## 核心功能

- **F1 知识库管理**：导入 TXT / Markdown / PDF / Word，自动清洗、切片、向量化入库。
- **F2 自然语言问答**：检索相关知识，生成带引用的回答。
- **F3 引用溯源**：回答附文档名称与原文片段，可核对出处。
- **F4 拒答机制**：相关度低于阈值或超出范围时明确告知「暂不了解」并引导咨询相关部门。
- **F5 反馈与日志**：点赞/点踩反馈，记录问答日志供评估使用。

## 技术选型

遵循「零成本、数据不出校、轻量可复现」三项约束：

| 组件 | 选用 | 理由 |
|---|---|---|
| 前端 | Streamlit | 纯 Python 完成交互界面，开发量最小 |
| 应用编排 | LangChain | 成熟的检索增强组件与社区资料 |
| 向量库 | FAISS | 轻量、本地文件索引、CPU 可用 |
| 模型运行时 | Ollama | 本地开源模型，零成本、离线可用 |
| 向量化 | 本地开源 embedding | 本地运行、零成本 |

整体采用分层架构：数据层负责文档切片与向量化入库；模型与检索层由 FAISS 检索 + Ollama 本地大模型推理组成；应用层用 LangChain 编排检索链与提示词；展示层由 Streamlit 提供网页交互。检索结果作为上下文约束生成，保证回答忠于知识库。

## 评估指标

| 指标 | 目标值 |
|---|---|
| 问答准确率 | ≥ 85% |
| 回答耗时 | P50 ≤ 10s，P90 ≤ 15s |
| 幻觉率 | ≤ 10% |
| 用户满意度 | ≥ 4.0 / 5 |
| 拒答准确率 | ≥ 80% |

评估采用「测试集 + 人工标注 + 问卷」组合方法，结果以图表形式汇总，反向指导系统迭代。

## 数据来源

全部来自学校公开发布的文本材料（教务处通知、学生工作部门文件、学生手册、后勤与保卫部门说明、教务 FAQ 等），无需爬虫、无付费数据源。计划整理不少于 50 条 FAQ，每条含【问题、标准答案、来源文档、整理时间】，落盘为 CSV/JSON，并保留原始文档副本。
